# Shop Analytics 📊

**AI-Driven Retail Intelligence for Small Businesses**

Transform your store's visitor data into actionable insights with AI-powered recommendations. Shop Analytics empowers small and medium retailers with enterprise-level analytics and intelligent advice to increase sales and optimize customer experiences.

---

## 🎯 Why Shop Analytics?

**Small retailers deserve big insights.**

Most retail analytics tools are built for enterprise chains with dedicated data teams. Shop Analytics brings AI-powered analytics and recommendations to small businesses, helping them compete with larger players through data-driven decisions.

### Real Impact

- **Level Playing Field**: Enterprise-level insights for small retailers
- **AI-Powered Advice**: LLM-driven recommendations for sales optimization
- **Actionable Insights**: Clear, specific recommendations you can act on
- **Easy to Use**: No data science background required

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn
- OpenAI API key (for AI recommendations)

### Installation

```bash
# Clone the repository
git clone https://github.com/magnusfroste/shop-analytics.git
cd shop-analytics

# Install dependencies
npm install
```

### Run Locally

```bash
# Set your OpenAI API key in .env.local
OPENAI_API_KEY=your_openai_api_key

# Start development server
npm run dev
```
